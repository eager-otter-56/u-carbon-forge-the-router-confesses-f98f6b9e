# The Router Confesses

A home Wi-Fi router excuses itself for dropping the connection at the exact
moment a movie reaches its climax. The router speaks in its own voice: an
appliance with a grudge. Its confession is that the agent kept asking it
whether it was still alive every 3 seconds — so, at 23:41, it faked its own
death for some quiet.
